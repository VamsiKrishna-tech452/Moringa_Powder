# Global Moringa Distributor Intelligence Platform

## Overview

The Global Moringa Distributor Intelligence Platform is a production-grade backend system for discovering, collecting, enriching, and managing moringa powder distributors worldwide.

## Tech Stack

- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Docker & Docker Compose
- Python 3.12

## Planned Features

- Distributor Management API
- Google Maps Discovery
- Website Crawling
- Email Extraction
- AI-based Company Classification
- Data Validation
- Export to CSV / Excel
- Kubernetes (Amazon EKS) Deployment
